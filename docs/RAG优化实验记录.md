## 实验记录

### 实验 #1：BM25 索引注入标题 ×2（2026-08-18）
- 改动：retriever._load_index 的 BM25 索引文本 = `title title + content`
- 结果：overall 0.892（1to1 0.920 / 1to2 0.864 / 1to3 0.863），MRR 0.831
- 对比：Recall -0.001（0.890→0.892 略升但 1to1 恶化 0.940→0.920）；改善 q070/q075，恶化 q024/q060/q069/q082
- 结论：**不采纳**（1to1 大面积恶化，标题 ×2 过强挤掉内容匹配块）

### 实验 #2：BM25 索引注入标题 ×1（2026-08-18）
- 改动：仅将标题注入次数从 ×2 改为 ×1（相对实验 #1 的单变量）
- 结果：overall 0.892（1to1 0.920 / 1to2 0.864 / 1to3 0.863），MRR 0.821
- 对比：与 #1 几乎相同，1to1 仍恶化（0.940→0.920），改善 q070/q075，恶化 q001/q060/q069
- 结论：**不采纳**（1to1 恶化模式不变），回滚 BM25 改动

### 实验 #3：删除重复文档（语料数据修复）（2026-08-18）✅ 采纳
- 问题：3 组重复文档（内容逐块 100% 相同，爬虫重复抓取）稀释检索池、挤占 top5：
  阿拉善 2·22（131块×2）、富洋 6·21（111块×2，全角/半角点）、凯信达 11·21（101块×2）；
- 改动：每组删除一个版本（Chroma 删块 343 + MySQL 删行 3）；
- 结果：overall 0.897（1to1 0.940 / 1to2 0.848 / 1to3 0.863），MRR 0.825，NDCG 0.877；
- 对比：Recall +0.007、MRR +0.005、NDCG +0.008；q085/q089 0.333→0.667（多块召回改善），无恶化；
- 结论：**采纳**。当前 RAG 仍为 v1.0（本次为数据修复，非检索算法变更）。

### 实验 #4：RRF 融合池 fusion_top_k 20→30（2026-08-18）
- 结果：overall 0.897 / MRR 0.825 / NDCG 0.877 —— 与实验 #3 完全相同；
- 结论：**不采纳**（无变化；rerank 取 top5 前排序未变，扩大融合池无收益）。

- 结论：**不采纳**（扩大向量召回稀释了 1to1 精度）。
